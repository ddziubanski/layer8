# Mobile companion

Technicians can open `/mobile` on the Layer 8 server for a compact ticket workspace. Sign in with an existing technician account; the same server-side roles, restricted queue rules and ticket APIs apply. Windows portal-only sessions remain limited to the requester portal.

The initial workspace provides open tickets by assignee or group, all-ticket search (including closed tickets), paginated results, ticket conversations, internal notes, portal replies and emailed replies. Attachments and other ticket tools remain available in the full console. It requires a working connection to the server; no ticket data is stored for offline use. Installable PWA support, push notifications, approvals, asset scanning and an Android package are future work.
